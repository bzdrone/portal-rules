Portal Rules Converter

View source on GitHub

Turn a Battlefield 6 Portal experience export into a TypeScript script and a strings file. Everything runs in your browser; nothing is uploaded.

The conversion is not complete. The script may have missing, approximate or wrong parts. Review it and test it in a copy of your experience.

1. Portal SDK typings

The converter reads the list of block and event names from the SDK's code/types/mod/index.d.ts. The SDK is EA's, so it is not included here: choose that file from your own SDK install. It is kept in this browser for next time.

No SDK loaded

Optional: pick sdk.version.json at the same time to record the version.

2. Your experience export

In the Portal web builder, open the Custom tab, click the three dots on your experience and choose Export. A bare workspace .json also works.

3. Result

Map

The export includes the map's spatial data (capture points, HQs, spawn points and so on). Tools such as a simulator need it; the script does not.
